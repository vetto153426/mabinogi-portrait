# 마비노기 포트레이트 메이커

**버전 v1.0.0** · 문의 · 수정/업데이트 요청 · 오류 제보: X(트위터) [@mabi_hp_sphie](https://x.com/mabi_hp_sphie)

빌드가 필요 없는 정적 사이트입니다. `index.html`, `fonts/`, `characters/`, `assets/` 만 있으면 동작합니다.

> 사용법·설정이 궁금하면 [AI-GUIDE.md](AI-GUIDE.md)를 AI(ChatGPT, Claude 등)에게 첨부하고 물어보세요. 설정, 위젯, 노션 임베드, 문제 해결이 정리되어 있습니다.

## 프로젝트 폴더 (git으로 내려받은 폴더)
GitHub에서 이 프로젝트를 git으로 내려받은 폴더(`index.html`이 있는 폴더)가 프로젝트 폴더입니다.

## 캐릭터 만들기
1. `index.html`을 브라우저(Chrome/Edge)로 엽니다.
2. ③ 저장·내보내기 탭에서 **프로젝트 폴더 연결**로 위 폴더를 선택합니다 (한 번만, 이후 유지).
3. ①캐릭터·이미지 → ②대사 설정 후, ③에서 **연결된 폴더에 저장**을 누릅니다.

## 캐릭터 폴더 구조
캐릭터 한 명 = 폴더 하나입니다.

```
characters/<ID>/character.json   설정(대사·색상·키워드 등)
characters/<ID>/stand.png ...    이미지/BGM 파일
characters/<ID>/desktop-<ID>.bat Electron 위젯 실행 파일 (더블클릭)
```
이 폴더를 직접 압축해 전달하면, 받는 사람은 자기 프로젝트의 `characters/` 안에 넣어 같은 방식으로 열 수 있습니다 (편집기 불러오기 · 노션 임베드 · 데스크탑 위젯 공통).

## 권장 작업 순서: 로컬에서 설정 → 완성본만 업로드
노션/웹 임베드로 쓰려면 **설정은 모두 내 PC(로컬)에서 끝낸 뒤, 완성된 `characters/<ID>/` 폴더만 올리세요.**
- 웹에 올린 화면은 **보는 용도**입니다. 편집은 로컬 `index.html`에서만 합니다.
- 올린 뒤에 고치고 싶으면 로컬에서 수정 → **연결된 폴더에 저장** → 다시 push 합니다.
- 올리기 전에 로컬에서 대사 · 키워드 · 화면(세로 길이, 배경 위치) · 용량을 확인하세요. 배포 후에 발견하면 용량이 큰 파일이 git 기록에 남습니다.

## 노션 임베드
- 처음 한 번: ③탭의 **“내 GitHub · Vercel에 한 번에 만들기”** 버튼(또는 [이 링크](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FLuhuina%2Fpublic-mabinogi-portrait-maker&project-name=mabinogi-portrait&repository-name=mabinogi-portrait))을 누르고 Vercel · GitHub에 로그인한 뒤, **“Create private Git Repository”(비공개 저장소)를 켠 상태로** Create → Deploy 하세요. 내 GitHub에 내 저장소가 만들어지고 Vercel 사이트가 자동으로 연결되며, 이후 push할 때마다 자동으로 배포됩니다. **내 저장소는 반드시 비공개(private)로 만드세요.** (공개 저장소에 올리면 이 프로그램을 재배포하는 것이 되어 이용 안내에 어긋납니다.)
- 이렇게 만든 내 저장소를 내 PC로 내려받아(git clone) 프로젝트 폴더로 쓰면 됩니다.
- 캐릭터 폴더를 GitHub 웹에서 올릴 때는 파일 1개당 25MB 제한이 있으니, 큰 파일은 git으로 올리세요.
- 캐릭터 추가/수정: 내 저장소의 `characters/` 에 폴더를 올리면 자동 재배포.
- 노션 `/임베드` → `https://<vercel주소>/?c=<ID>`

## 데스크탑 위젯 (Electron)
`characters/<ID>/desktop-<ID>.bat` 를 더블클릭. 자세한 내용은 `desktop/README.md`.

## 업로드 용량 (GitHub · Vercel)
캐릭터 파일(스탠딩 · 배경 gif · BGM)이 용량의 대부분입니다. 올리기 전에 확인하세요.

| 항목 | 기준 |
| --- | --- |
| GitHub 파일 1개 | 50MB 넘으면 경고, **100MB 넘으면 업로드 거부** |
| GitHub 저장소 전체 | 1GB 이하 권장 (캐릭터 폴더가 쌓이면 빨리 늘어납니다) |
| Vercel 무료(Hobby) | 방문할 때마다 파일이 전송되므로 월 전송량 한도가 있습니다. 큰 gif · mp3는 한도를 빨리 소모하고 노션에서 로딩도 느려집니다 |

권장 크기: 배경 gif **20MB 이하**, BGM mp3 **10MB 이하**, 스탠딩 png **5MB 이하**. 용량이 크면 gif는 프레임 수 · 해상도를 줄이고, 배경이 움직일 필요가 없으면 png/jpg를 쓰고, mp3는 128kbps 정도로 줄이세요. 한 번 올린 큰 파일은 git 기록에 남아 저장소 용량을 계속 차지하니, 올리기 전에 줄이는 것이 좋습니다.

## 노션 임베드 화면 크기
임베드 화면은 노션 임베드 창을 **가득 채우도록 확대**됩니다 (검은 여백 없음). 창 비율이 캐릭터 화면 비율(기본 1840 : 982, 편집기에서 세로 길이를 늘렸다면 그 비율)과 다르면 위쪽·양옆이 조금 잘릴 수 있고, 아래쪽(대사창)은 항상 보입니다. 잘림 없이 전체를 보려면 ③탭의 “권장 임베드 비율”에 맞춰 노션 임베드 창 크기를 조절하세요.

## 보안 · 주의
- **Vercel 배포 주소(`https://○○○.vercel.app`)는 누구나 접속할 수 있습니다.** 주소를 아는 사람이라면 로그인 없이 캐릭터 화면을 볼 수 있고, `characters/` 안의 모든 파일(이미지 · 음악 · `.bat`)도 내려받을 수 있습니다. GitHub 저장소를 비공개(private)로 해도 **Vercel로 배포된 웹사이트는 공개**입니다(저장소 공개 여부와 별개). 공개하고 싶지 않은 파일은 올리지 마세요.
- **환경변수에 비밀 키를 추가한다고 해서 사이트가 비공개가 되지는 않습니다.** 환경변수는 서버 코드가 읽어서 확인할 때만 쓰이는데, 이 프로젝트는 서버 코드가 없는 정적 사이트라 키를 확인하지 않습니다. 비공개로 쓰고 싶다면 웹에 올리지 말고 내 PC에서 데스크탑 위젯으로만 사용하세요.
- **남에게 받은 캐릭터 폴더의 `.bat`은 실행하기 전에 내용을 확인하세요.** 내 PC에서 실행되는 명령 파일입니다. 메모장으로 열어 확인하거나 지우고 편집기에서 다시 만드세요. `character.json`에 외부 주소(`https://...`)가 들어 있지 않은지도 확인하세요.
- 배포 설정(`vercel.json`)에 보안 헤더(CSP, nosniff, Referrer-Policy, Permissions-Policy)가 들어 있어, 페이지가 외부 파일을 불러오거나 카메라·마이크 등을 쓰지 못하게 막습니다. 노션 같은 곳에 **임베드하는 것(iframe)은 허용**됩니다.
- 위젯(Electron)은 이 PC의 `127.0.0.1`에서만 파일을 제공하고 `index.html`, `characters`, `fonts`, `assets` 밖은 열지 않으며, 외부 사이트로 이동하지 않습니다.
- 인증 키 · 토큰 · 비밀번호는 이 프로젝트에 저장하지 말고 저장소에도 올리지 마세요.

- **상업적 사용 금지**: 이 프로그램과 이를 이용해 만든 결과물을 판매하거나 수익 목적으로 사용하지 마세요. (비영리 개인 · 팬 활동 용도)

- **재배포 금지**: 이 프로그램의 파일(수정본 포함)을 작성자가 안내한 공식 배포처 외의 다른 경로로 다시 올리거나 나눠주지 마세요. 소개나 공유는 공식 배포처 주소로 해 주세요.
- 수정 · 업데이트 요청과 오류 제보는 X(트위터) [@mabi_hp_sphie](https://x.com/mabi_hp_sphie)로 보내 주세요.
