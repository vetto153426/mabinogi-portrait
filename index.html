키워드 대화

키워드 왼쪽 체크박스를 켜면 책에 그 키워드가 표시됩니다 (기초회화는 항상 표시). 대사를 입력하면 자동으로 체크됩니다. 책에서 키워드를 누르면 입력한 대사 중 하나가 랜덤으로 나오고, 대사가 없으면 위쪽 ‘모르는 키워드 대사’가 나옵니다. (○ 미입력 / ● 입력됨)

책갈피 표시 규칙 기초·중급·고급회화와 정보메모는 항상 표시됩니다 (기초회화는 모든 키워드, 나머지는 체크한 키워드만 내용에 나타남).
교우관계·선물반응은 직접 추가한 키워드가 있을 때만 표시됩니다. 키워드 왼쪽 ⠿ 를 끌어 순서를 바꿀 수 있습니다.

2노션 임베드 (Vercel)

▲ 내 GitHub · Vercel에 한 번에 만들기

처음 한 번만: 위 버튼 → Vercel · GitHub 로그인 → “Create private Git Repository”(비공개 저장소)를 켠 상태로 Create → Deploy. 내 GitHub에 내 저장소가 만들어지고 Vercel 사이트가 자동으로 연결됩니다. 만들어진 사이트 주소(○○○.vercel.app)를 아래에 입력하세요.

설정은 이 화면(내 PC)에서 끝낸 뒤 완성된 캐릭터 폴더만 올리세요. 내 비공개(private) GitHub 저장소를 Vercel에 연결해 두면, characters/ 폴더에 캐릭터 폴더를 올릴 때마다(git push 또는 GitHub 웹 업로드) 자동으로 배포됩니다. 자세한 방법은 README.md · AI-GUIDE.md를 참고하세요.

Vercel 배포 주소(○○○.vercel.app)는 주소를 아는 누구나 볼 수 있습니다. 저장소를 비공개로 해도 마찬가지이니, 공개하고 싶지 않은 파일은 올리지 마세요.

임베드 화면은 창을 가득 채우도록 확대됩니다 (여백 없음). 창 비율이 와 다르면 위쪽·양옆이 조금 잘릴 수 있으니, 이 비율에 맞추면 잘림 없이 전체가 보입니다.

노션에서 /임베드로 위 주소를 붙여넣으세요. 캐릭터가 여러 명이면 ?c= 뒤의 ID(캐릭터 폴더 이름)만 바꾸면 됩니다.

3데스크탑 위젯 (Electron)

별도 프로그램 창으로 열립니다. 테두리 없음 · 항상 위 · 끌어서 이동 · 오른쪽 클릭 메뉴(항상 위/크기/투명도/재생바/닫기). 창 위치와 크기는 캐릭터별로 기억됩니다.

사용 방법 프로젝트 폴더를 연결해 두면 characters/ID/ 안에 desktop-ID.bat이 저장됩니다. 더블클릭하면 위젯이 열립니다 (처음 한 번 Node.js가 필요하고, 첫 실행 때 Electron이 자동 설치됩니다).
캐릭터 폴더를 통째로 옮기거나 공유해도 실행 파일이 함께 따라갑니다. 폴더를 연결하지 않으면 다운로드되며, 윈도우가 차단하면 파일 우클릭 → 속성 → ‘차단 해제’를 하세요.
