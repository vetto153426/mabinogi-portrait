캐릭터 한 명 = 폴더 하나입니다.

  characters/<ID>/character.json      설정
  characters/<ID>/stand.png ...       스탠딩 / 배경 / BGM 파일
  characters/<ID>/desktop-<ID>.bat    Electron 위젯 실행 파일

편집기(index.html)의 "③ 저장 · 공유" 탭에서 프로젝트 폴더를 연결하고 "연결된 폴더에 저장"을 누르면 자동으로 만들어집니다.
노션 임베드 주소 예)  https://내사이트.vercel.app/?c=<ID>

주의: Vercel 배포 주소(https://○○○.vercel.app)로 배포하면 이 폴더 안의 파일은 주소를 아는 누구나 볼 수 있습니다. 남에게 받은 폴더의 .bat은 실행 전에 내용을 확인하세요.
